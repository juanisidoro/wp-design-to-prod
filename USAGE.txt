wpkit — cambios de WordPress (staging <-> produccion) con backups y auto-rollback

COMANDOS
  wpkit new <cambio>                  Crea la carpeta de un cambio nuevo (desde plantilla)
  wpkit dev <cambio> <sitio>          Bucle rapido en staging: aplica + flush, SIN backup (itera CSS)
  wpkit apply <cambio> <sitio>        Aplica el cambio a un sitio (backup + verifica + auto-rollback)
       opciones:  --dry-run   muestra el plan sin ejecutar nada
                  --yes       no pide la confirmacion de produccion
                  --force     salta el aviso de "no probado en staging"
  wpkit rollback <cambio> <sitio>     Deshace el cambio en ese sitio
  wpkit list                          Lista los cambios y su estado (staging/prod)
  wpkit help                          Esta ayuda

FLUJO TIPICO
  wpkit new footer
  # editar changes/footer/style.css (CSS) o apply.php (estructura)
  wpkit dev footer staging.example.com       # bucle rapido: editar -> dev -> ver, las veces que haga falta
  wpkit apply footer example.com             # publicar en produccion (backup + verifica)

SEGURIDAD
  - Copia catastrofica (db+wp-content+wp-config) ANTES de tocar nada.
  - apply.php idempotente; si falla -> rollback automatico.
  - Verificacion del render; si falla -> rollback automatico.
  - En produccion: pide confirmacion y avisa si no se probo en staging.
  - El CHANGELOG se escribe en /var/www/<sitio>/updates/ (INDEPENDIENTE de wpkit).
