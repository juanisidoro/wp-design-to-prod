# Cambio: example-css-tweak

Un ejemplo minimo y autocontenido de un cambio wpkit.

**Que hace:** anade un bloque de Additional CSS marcado que colorea los enlaces del footer.

**Que toca:** solo Additional CSS (bloque `=== EXAMPLE CSS TWEAK ===`).

**Probar:**    `wpkit apply example-css-tweak staging.example.com`
**Publicar:**  `wpkit apply example-css-tweak example.com`
**Revertir:**  `wpkit rollback example-css-tweak <sitio>`

> Edita `meta.json` con tus dominios reales de staging/produccion antes de usarlo.
